# 验证说明

## 实时识别验证

1. 启动后端，默认端口为 `8010`。
2. 启动前端，默认端口为 `5173`。
3. 播放默认视频。
4. 观察车辆框是否覆盖当前画面中的车辆。
5. 拖动视频进度条到任意位置。
6. 确认 AR 框和信息卡片根据当前画面重新出现。
7. 选择另一段本地汽车视频。
8. 确认仍能基于当前帧检测车辆，而不是按预设时间显示。

## 语音和问答验证

1. 点击车辆上的轮毂、车窗或车身区域。
2. 浏览器应播报该部位说明。
3. 输入或语音询问：这个车型有什么优惠么？
4. 后端应查询 `backend/app/data/offers.json` 并返回优惠。
5. 页面应展示优惠卡片并播报回答。

## 降级验证

1. 不配置 `LLM_API_KEY`。
2. 询问优惠或部位问题。
3. 系统应使用本地规则回答，不应报错。

## 调试指标

页面右上角应展示：

- Detection
- Frame ID
- Latency
- Vehicles
- Parts: geometry estimated
- Mode: realtime frame detection
